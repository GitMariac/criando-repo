GitHub e Git

O GitHub é uma plataforma para criação de software que reúne ferramentas e fluxos de trabalho para diferentes etapas do desenvolvimento.

O que é o Git?

Segundo a documentação oficial do GitHub, o Git é um sistema de controle de versão distribuído que acompanha as alterações realizadas nos arquivos de um projeto. Ele permite registrar um histórico das modificações e recuperar versões anteriores quando necessário.

Em um projeto, os desenvolvedores podem trabalhar em suas próprias cópias, registrar suas alterações e posteriormente combinar seu trabalho com o de outros integrantes. Os commits funcionam como registros das alterações, enquanto os branches permitem trabalhar em diferentes linhas de desenvolvimento.

Por que o GitHub é importante?

O GitHub utiliza o Git como base para hospedar repositórios e acrescenta recursos voltados à colaboração. Dessa forma, equipes podem armazenar código, acompanhar alterações, revisar contribuições e trabalhar de maneira organizada em projetos de software.
